## Install

Pick the download that matches your device. All builds come from the same source and have the same features.

| Platform | Where to get it |
|---|---|
| Windows 10 / 11 | [Microsoft Store](https://apps.microsoft.com/detail/9NN162Z0WXSR) or [NSIS installer](https://github.com/infinitel8p/Extreme-InfiniTV/releases/latest) |
| Android phone / tablet / TV | [Google Play](https://play.google.com/store/apps/details?id=com.infinitel8p.xtream) or APK from [Releases](https://github.com/infinitel8p/Extreme-InfiniTV/releases/latest) |
| macOS | `.dmg` from [Releases](https://github.com/infinitel8p/Extreme-InfiniTV/releases/latest) |
| Linux | [Snap Store](https://snapcraft.io/extreme-infinitv) (`sudo snap install extreme-infinitv`), or `.AppImage` / `.deb` / `.rpm` from [Releases](https://github.com/infinitel8p/Extreme-InfiniTV/releases/latest) |
| Raspberry Pi 4 / 5 | 64-bit OS required. Same Snap install, or the arm64 `.deb` / `.AppImage` from [Releases](https://github.com/infinitel8p/Extreme-InfiniTV/releases/latest) |

The Windows desktop build and the Linux AppImage auto-update from GitHub Releases; you can turn this off with the **Automatic updates** toggle in **Settings > About > App update** (the toggle only appears on builds that have the updater). The Microsoft Store, Google Play, and the Snap Store handle updates themselves. Other Linux packages (deb / rpm) do not auto-update. On platforms without a built-in updater (web, macOS, and Microsoft Store / MSIX builds), the app shows a hint when a newer version is available; Play Store installs link straight to Google Play.

### Beta updates

To try new features early, open **Settings > About > App update** and switch the **Update channel** to **Beta**. Beta builds ship more often and may be unstable. Updating to one works right from the app, the same way as a stable release. The channel picker is hidden on Microsoft Store and Snap installs, since those stores manage updates themselves (and only ship stable releases).

### Install via winget (Windows)

If you prefer the command line, install directly from the Microsoft Store source:

```powershell
winget install --id 9NN162Z0WXSR --source msstore
```

You get the same build as the Store, including automatic updates.

### macOS: "Extreme InfiniTV.app" cannot be opened

The macOS build is not yet notarized by Apple, so Gatekeeper blocks it on first launch with a message like *"Apple could not verify Extreme InfiniTV.app is free of malware"*. After dragging the app from the `.dmg` into `/Applications`, remove the quarantine flag from a Terminal:

```bash
xattr -dr com.apple.quarantine "/Applications/Extreme InfiniTV.app"
```

Then open the app normally. You only need to do this once per install.

<Callout type="tip">
  This is a one-time step until a notarized macOS build ships. The command is safe: it strips the `com.apple.quarantine` extended attribute that Gatekeeper sets on downloads, nothing more.
</Callout>

## First launch

1. Open the app. You'll land on the login screen.
2. Paste your **Server URL**. Include the port if your provider gave you one.
3. Fill in **Username** and **Password** if your provider gave you separate credentials. If they only gave you a single M3U URL, leave these blank.
4. The app connects, loads your channels, and takes you to the home screen.

You only need to sign in once. The app remembers your details for next time.

<Callout type="tip">
  No provider yet? The login screen offers a **Demo (iptv-org)** playlist - a free public playlist you can use to explore the app and remove any time. More on setting up Xtream credentials, M3U URLs, and multiple playlists in [Playlists (Xtream + M3U)](./playlists/).
</Callout>

## What's on the home screen

- **Live TV / Movies / Series** - three big tiles that take you to your channel list (with categories and now / next), and the movie and series poster grids.
- **Content strips** below the tiles: by default **Continue watching**, **Favorites**, **Watchlist**, **Because you watched**, and **Recently added**. You choose which strips show and in what order under **Settings > Appearance > Home page sections**.
- **Because you watched** matches titles against the rest of your library right on your device - no account or API key needed. Turn on [TMDB metadata](./tmdb-metadata/) for richer detail pages with cast, director, and similar titles.
- **Sidebar** on desktop, or a **bottom tab bar** on phones, for jumping between Live TV, Movies, Series, Favorites, Watchlist, Downloads, Search, EPG, and Settings. On wider screens, collapse the sidebar to icons-only with the button at its top to free up space.

## Finding something to watch

- **Context menus** - right-click (or long-press on touch) a poster or channel card, on the home screen or anywhere else, for quick actions: open, add to favorites or the watchlist, mark as watched, and for movies, download or copy the stream URL.
- **Surprise me** - the dice button on the Movies and Series pages picks a random title for you, with optional filters for year and "not watched yet". Roll again if it's not what you're after.
- **Hide watched** - the view menu on the Movies and Series grids can hide anything you've already finished.
- **Recent searches** - open search with <kbd>Ctrl</kbd> <kbd>K</kbd> and your last few searches show up before you type anything, so you can jump back in or clear them.
